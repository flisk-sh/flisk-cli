# AGENTS.md

This project runs on [Flisk](https://github.com/flisk-sh/flisk-cli). To build or run something here, follow the Flisk skills in `.agents/skills` (Claude Code: `.claude/skills`), starting with `flisk-build`.

- Add a service: `flisk resource <name> --type <frontend|backend|worker|agent|mcp> --stack <stack> --yes`
- Start it: `flisk up <stack>`, then `flisk status --json`: every resource must be `ready`; request `<url or directUrl>/health` of each
- When something fails: `flisk doctor`, then `flisk logs -s <service>`
- Do not hand-write Dockerfiles, Compose files or Tiltfiles. Do not edit the files Flisk generates (`.autogenerated/` folders, `.flisk/.flisk-out/`, `Tiltfile`, `TILT_*.star`, `.tiltignore`): `flisk up` writes them again. Change `service.json` instead; `flisk config explain <file>` says where a file comes from.

## Working with several agents

- Give each agent its own git worktree (`git worktree add ../<project>-<agent>`), so two agents never edit the same checkout.
- Install [Run My Agents](https://github.com/flisk-sh/run-my-agents) (`/plugin marketplace add flisk-sh/run-my-agents`, then `/plugin install run-my-agents@run-my-agents`): it stops an edit once when another agent changed the same file in the last few minutes.
- Run `flisk status --json` before starting a stack, so an agent sees what is already running.
